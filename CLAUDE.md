# CLAUDE.md — 4ONE Launcher

Лаунчер проекта **4ONE RP** (GTA V roleplay). Electron 33, Windows-first. Один аккаунт с сайтом и игрой: вход через OAuth (браузер → `gta4one://auth/callback`), роль и баланс 4Coin — из игровой MariaDB через **Core API** (`backend/core-api/`).  Серверы, новости, промокоды и данные аккаунта — тоже Core API: Supabase не используется.
Читайте этот файл первым. Детали — в `docs/`.

## Быстрый старт
```bash
npm i
npm run start:mock      # окно Electron на демо-данных, без сети и без GTA
npm run preview         # то же в браузере: http://localhost:4173/#ready  (#login #not-installed #update #no-gta #downloading #ingame #offline)
npm test                # node --test, без зависимостей
npm run shots           # скриншоты всех экранов (на Linux нужен xvfb) -> shots/
npm run icons           # пересобрать спрайт иконок (Lucide) из tools/icons-map.js (Lucide)
npm run dist            # установщик NSIS (на Windows) -> dist/
```
Демо-вход: кнопка «Войти через сайт» входит сама; сценарий `#admin` — администратор 5 уровня. Промокоды демо: `WELCOME4` (+100 4Coin), `CARSET01` (авто), ошибки: `USED0000`, `EXPIRED0`, `LIMIT000`.

## Карта репозитория
| Путь | Что |
|---|---|
| `src/core/` | **Контракт** (`contract.js`: каналы IPC, события, ошибки с русскими текстами) и чистые обработчики (`handlers.js`). Без electron и node-API — работают и в браузерном предпросмотре |
| `src/main/` | Процесс main: окно, трей, deep-link, сессия (OAuth), клиенты Core API, установка клиента, запуск игры, автообновление |
| `src/preload/index.js` | Единственный мост `window.l4` (`call`, `on`). Списки каналов продублированы вручную (sandbox) — сверяет `test/contract.test.js` |
| `src/mock/` | Мок-сервисы для демо и тестов (чистый JS) |
| `src/renderer/` | Интерфейс: ES-модули без сборщика; `css/` токены и компоненты, `js/screens/` экраны (home, news, codes, account, settings, login) |
| `backend/core-api/` | **Единый API** (Node, MariaDB игры): OAuth (Authorization Code + PKCE), профиль и роль (`alvl`), каталог серверов/новостей, промокоды, раздел «Аккаунт»; см. его README. Тесты: `cd backend/core-api && npm test` |
| `backend/supabase/` | **Устарело**, не используется (см. `DEPRECATED.md` в папке); можно удалить |
| `tools/` | Предпросмотр, скриншоты, иконки, публикация обновлений |
| `docs/` | ARCHITECTURE, DESIGN, API, TASKS, OLD-LAUNCHER |

## Правила (не нарушать)
1. **Сеть только в main** (и только к Core API `config.core.url` и статике `config.cdn`). Рендерер под CSP `connect-src 'none'`; `fetch` в `src/renderer` запрещён. Новое действие = канал в `contract.js` → обработчик в `handlers.js` → сервис в main/mock → дубль в `preload/index.js` → `npm test`.
2. **Секреты.** Токены (access/refresh) только через `safeStorage` (`session.js`), не в `settings.json`, не в логах (`logger.js` вырезает). Никаких ключей `service_role` в репозитории.
3. **Внешние ссылки** только через `app:openExternal` с ключом из `config.links` или https-URL с хостом из `externalHostAllowlist`.
4. **Файловые операции с игрой** — только через `client/installer.js` + `manifest.js` (`safeJoin`, allowlist расширений, SHA-256, `.part` + атомарное переименование). Не писать мимо.
5. **Ошибки** — только коды из `ERRORS`; текст для игрока русский, без стека и технических деталей, с тем, что делать дальше.
6. **Интерфейс** строится по `docs/DESIGN.md`: токены из `css/tokens.css`, три радиуса (6/10/16), без blur/backdrop-filter, анимации только `transform`/`opacity` (у `.pb` ещё `width`), одно настоящее лого на экран (`assets/logo/*`), логотип не перерисовывать и не использовать как фон/узор. Иконки — только из спрайта (Lucide, тонкий контур; логотипы брендов — Phosphor regular; список в `tools/icons-map.js`, после правки `npm run icons`), не подключать другие наборы и эмодзи. Подписи без капса и без жирности выше 700.
7. **4Coin** — всегда шампань (`--champ`) и с подписью «4Coin»; доллары — жемчуг (`--pearl`).
8. **Языки (RU/EN).** Исходный язык — русский: строка в коде — это ключ `t('Русский текст')` (`renderer/js/i18n.js`), перевод — в `renderer/js/i18n-en.js`. Новая строка = `t()` + запись в EN, иначе упадёт `test/i18n.test.js`. Подстановки `{имя}`, не склейка строк. Константы с текстом — функции/геттеры (язык меняется на лету). Тексты ошибок переводятся по русскому тексту из `ERRORS` в `api.js`; тосты main — по русскому тексту; трей и диалоги Electron — `src/main/i18n.js`. Язык хранится в настройке `lang` (`ru|en`), по умолчанию `ru`.
9. **Поля кодов**: только A–Z, 0–9 (в промокоде ещё «-»), жёсткий лимит (вход 8 знаков, промокод 16) — `renderer/js/codefmt.js`. Не добавлять свободные текстовые поля без лимита.
10. **Тексты**: русский, предложения с заглавной, кнопки — глагол («Установить», «Играть»), без «Ок/Submit». Пустое состояние объясняет, что делать.
11. **Адаптив.** Окно от 640×480 до ультраширокого: масштаб `--z` на `.app` (авто по размеру окна или настройка «Масштаб», `js/scale.js`), раскладка на контейнерных запросах (`@container app|view`) и `cqw`, а не `vw`. Фиксированных ширин, которые ломаются на узком окне, быть не должно — проверяйте экран на 640×480, 1280×760 и 3440×1440.
12. **Настройки и вкладки не перерисовывают страницу.** Страницы с вкладками (`js/tabs.js`) строятся один раз, переключатели только выставляют значения у существующих элементов (`sync()` в `settings.js`). Любое `render()` на смену настройки — баг: прокрутка и фокус сбрасываются.
13. Тесты не должны требовать сети/Windows. Новый модуль с логикой — тест рядом.

## Что НЕ проверено (честно)
Сборка и запуск на Windows, реальный Core API, реальная установка в папку GTA V, FloVMP.asi, автообновление. Подробности и список допущений — `docs/TASKS.md`. Не считайте их работающими, пока не проверите.
Также не проверено: Core API на живой MariaDB и боевой адрес `L4_CORE_URL` (в `config.js` — предположение `https://api.4onerp.com`), регистрация протокола `gta4one://` и возврат из браузера на Windows. Пять тестов (`api`, `download`) в песочнице без локальных портов падают с `EPERM` — это окружение, не код.

## Стиль кода
CommonJS в `src/main|core|mock|preload`, ES-модули в `src/renderer`. Без TypeScript и сборщика (осознанно: проект маленький, `npm i` и `electron .`). Комментарии по-русски, коротко, «почему», а не «что». Отступ 2 пробела, одинарные кавычки.
