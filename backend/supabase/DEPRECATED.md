# Устарело: Supabase больше не используется

Лаунчер работает только с Core API (`../core-api`): вход, профиль и роль, серверы, новости, промокоды и данные аккаунта лежат в игровой MariaDB.
Эти миграция и Edge Functions были предложением, ни разу не развёртывались и лаунчером не вызываются. Папку можно удалить целиком.
