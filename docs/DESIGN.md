# Дизайн-система лаунчера

Основа — дизайн-система 4ONE из игры (v5): графит с баклажанным оттенком, один акцент, три радиуса, спокойное движение. Стилистику сайта не используем. Токены лежат в `src/renderer/css/tokens.css` — менять только там.

## Токены
| Группа | Значения |
|---|---|
| Поверхности | `--bg #100e12`, `--p1 #1b1820`, `--p2 #221f29`, `--p3 #2c2934`, `--p4 #37343f`, `--p5 #47444f` |
| Текст | `--t1 #f4f1f6`, `--t2` .74, `--t3` .58, `--t4` .40 (вторичный текст серый, не акцентный) |
| Акцент | `--ac #b9a3ff`, `--ac2 #7d63e8`, кнопки `--btn-a/--btn-b`; варианты `data-accent="mint|rose|sky"` (настройка «Цвет интерфейса») |
| Смысл | `--ok #8fc2a8`, `--no #c8566f`, `--warn #dcc49c` — только для статусов |
| Валюты | 4Coin `--champ #dcc49c` (всегда с подписью «4Coin»), доллары `--pearl #e6e0ec` |
| Радиусы | `--r1 6px` (мелочи, чипы), `--r2 10px` (кнопки, поля, строки), `--r3 16px` (окна, панели). Больше радиусов не добавлять |
| Движение | `--ease cubic-bezier(.22,1,.36,1)`; вход экрана `.24s` fade + 10 px; подсветка 100–150 мс; без пружин; `prefers-reduced-motion` учтён |
| Шрифт | Onest (локально, `assets/fonts`), веса 500/600/700/800; цифры `tabular-nums` |

Запреты: `backdrop-filter`/blur, полупрозрачные логотипы и узоры на фоне, второе лого на экране, самодельные иллюстрации и логотипы, градиентные «стеклянные» плашки, анимация `top/left/height`.

## Компоненты (`css/components.css`)
`.gp` панель (+`.flat`), `.gh` заголовок панели (иконка-плитка + капс), `.cd` карточка/строка (+`.hv`, `.sel`), `.bt` кнопка (`.g` вторичная, `.dng` опасная, `.sm`, `.xl`, `.wide`, `.busy`), `.ib` иконка-кнопка, `.ch` чип-фильтр, `.bdg` бейдж (`.ok .no .warn .mute`), `.inp` поле (`.code` для кода), `.sw` переключатель, `.pb` прогресс (`--p` 0..1), `.kv` пара «ключ — значение», `.dot` статус, `.empty`, `.sk` скелетон, `toast`, `modal`, баннеры. Состояния есть у всех: hover, active, focus-visible (контур акцентом), disabled.

## Язык форм и иконки
Логотип 4ONE угловой (срезы 45°), поэтому и фирменные элементы лаунчера угловые: плитка сервера и значок баннера со срезанными углами (`clip-path`), иконки собственного набора.
**Иконки** — Lucide (ISC), контур 1.75 px, размеры 15–20 px; логотипы брендов (Discord, Telegram, Steam, Google, YouTube) — Phosphor regular, т.к. в Lucide их нет; в спрайт попадают только нужные (`tools/icons-map.js` → `npm run icons`). Подключение: `ic('имя')` из `js/ui.js` → `<svg class="i"><use href="#i-имя">`. Новая иконка = строка в `icons-map.js` + `npm run icons`. У VK в наборе нет иконки — используется текстовый значок.

## Адаптивность
Окно 640×480 … ультраширокое (минимум задан в `main/index.js`). Масштаб: `--z` на `.app` (CSS `zoom`), авто = `clamp(min(w/1160, h/700), 0.72, 1.6)` или значение из настроек (90–150%). Раскладка — контейнерные запросы: `@container app` (панель уходит вниз полосой при <760 px), `@container view` (сетки схлопываются, вкладки аккаунта/настроек становятся лентой). Размеры шрифтов героя — `clamp()` + `cqw`.

Левая панель как в Majestic: логотип, разделы строками (иконка + подпись, счётчик новостей), снизу карточка профиля (аватар, имя, 4Coin) и шестерёнка настроек. Окно уже 1000 px — только иконки с подсказками, уже 760 px — полоса снизу. Индикатор активного раздела один и плавно переезжает; баланс 4Coin — в карточке профиля (в узком режиме числом под аватаром); в титлбаре баланса нет. Горячие клавиши Ctrl+1…5.
Заголовок окна: статус сети, «Сейчас играют N», версия, кнопки окна. Баннеры сверху: нет связи, обновление лаунчера, объявление проекта.

## Кнопки и текст
- Три размера кнопок: `.bt.sm` 34px, `.bt` 42px, `.bt.xl` 56px (главное действие, «Играть»); иконка-кнопки `.ib` 38px и `.ib.lg` 56px (рядом с «Играть»). Поле ввода в одной строке с кнопкой — 46px, кнопка в этой строке тоже 46px.
- Эффект у всех `.bt` и `.ib.lg` один: градиент, внутренний блик, «прожектор» под курсором (`--mx/--my` ставит `main.js`), подъём и свечение на hover, нажатие на active. Только `transform`/`opacity`; при `data-motion=off` и reduced motion подъём отключён.
- Неинформативного текста не добавлять: нет подзаголовков под заголовками экранов, нет версии GTA и статуса «готово к запуску». Строка статуса под «Играть» показывается только когда есть что сообщить (ошибка, обновление, установка).

## Состояния кнопки «Играть» (`js/gamephase.js` — единственное место перевода фазы в текст)
Проверка → «Указать GTA V» / «Нужна GTA V Legacy» (отключена) / «Установить» / «Обновить» → «Установка N%» с прогрессом, скоростью, остатком и «Отмена» → «Запуск…» → «В игре». Недоступен сервер или нет сети — кнопка отключена с причиной рядом.

## Ориентиры (исследованы 2026-10-26)
Смотрели Rejoin, Majestic и GTA5RP. Взято как приём, не как стиль: счётчик «Сейчас играют» (все три), список серверов строками с «Играть» и блоками «Рекомендуем / Заходили в последний раз / Все» (Majestic), баннер для тех, у кого нет игры (GTA5RP), минимализм и крупный арт без лишних рамок (Rejoin). Цвета, шрифты, формы и иконки — свои.

## Скриншоты и проверка
`npm run shots` снимает все экраны и состояния (вход, ошибка входа, главная в 8 сценариях, серверы, новости, коды, профиль, настройки, подтверждение). Перед правкой UI снимите «до», после — «после».
Известные ограничения: нет оригинальной векторной версии логотипа (используется растр из игры — при смене DPI лучше заменить на SVG), нет настоящего hero-арта (используются рендеры автомобилей из игры; для новостей без обложки — плитка с иконкой категории).

## Языки и поля ввода
- Два языка: русский (по умолчанию) и English. Переключатель — в «Настройки → Лаунчер» и в углу экрана входа. Смена применяется сразу, без перезапуска.
- Английский текст короче или равен русскому по смыслу, предложения с заглавной, кнопки — глагол («Play», «Install», «Redeem»). Единицы и даты: `ГБ/МБ/мин` ↔ `GB/MB/min`, `18 окт` ↔ `18 Oct`, числа `1 250` ↔ `1,250`.
- Поля кодов принимают только латиницу и цифры и режут длину в самом поле: вход — 8 знаков (`XXXX-XXXX`), промокод — 16. Русская раскладка не мешает: набранная кириллица превращается в ту же клавишу на латинице (ф→A), вставка кириллицы отбрасывается с подсказкой.
