# Выпуск лаунчера и комплекта клиента

## Что отдать тестеру
`dist/4ONE-Launcher-Setup-<версия>.exe` (копия — `release-assets/` в папке проекта). Установщик ставит лаунчер в профиль пользователя (`%LOCALAPPDATA%\Programs\4ONE Launcher`), права администратора не нужны.

Мастер установки на русском:
1. Приветствие.
2. Выбор папки.
3. Установка.
4. Галочка «Запустить 4ONE Launcher».

Ярлыки создаются на рабочем столе и в «Пуске». Протокол `gta4one://` регистрирует само приложение при первом запуске.

При удалении установщик спрашивает, стереть ли настройки и скачанный клиент. При обновлении этот вопрос не задаётся.

Подписи кода нет, поэтому Windows SmartScreen покажет «Неизвестный издатель»: нужно нажать «Подробнее» → «Выполнить в любом случае». Чтобы убрать предупреждение, задайте `CSC_LINK` и `CSC_KEY_PASSWORD` (сертификат подписи кода) и пересоберите.

## Сценарий тестера
1. Запустить лаунчер.
2. Нажать «Войти через сайт» (логин и пароль игрового аккаунта) или «Играть без входа», если аккаунта ещё нет. Регистрация проходит в самой игре.
3. Лаунчер сам находит GTA V Legacy (Rockstar, Steam, Epic). Если не нашёл — указать папку.
4. Нажать «Установить». Лаунчер:
   - скачивает комплект клиента (https, SHA-256);
   - распаковывает его в `%LOCALAPPDATA%\4ONE Launcher\client-kit`;
   - вызывает установщик платформы.

   Если GTA лежит в `Program Files`, один раз появится запрос UAC.
5. Нажать «Играть»: платформа обновляет клиент и моды сервера, запускает GTA V и подключает к серверу.

## Публикация (только по решению владельца)
1. **Комплект клиента 1.1.3.** Zip уже собран и проверен: `release-assets/4ONE-client-1.1.3.zip`. Подпись проекта и SHA-256 всех файлов сходятся, `server.txt` указывает на `188.130.132.47:7788`.
   - Выложить как prerelease `client-1.1.3` в GitHub `4one-rp-dev/launcher`.
   - Затем выполнить на VDS SQL из `release-assets/client-1.1.3.sql`. Делать это строго после выкладки, иначе ссылка будет битой.
   - Пока bootstrap отдаёт 1.1.1, всё тоже работает: платформа сама обновит клиент до 1.1.3 с игрового сервера при первом входе (около 460 МБ сверху).
2. **Лаунчер.** Создать релиз `v<версия>` в `4one-rp-dev/launcher` и приложить `latest.yml`, `4ONE-Launcher-Setup-<версия>.exe` и `.blockmap` из `dist/`. Уже установленные лаунчеры сами предложат обновление.
3. **Ссылки разделов** (Discord, донат, правила, форум, поддержка) задаются на сервере без новой версии лаунчера. Пока ссылки не заданы, лаунчер показывает только «Сайт».
   ```sql
   INSERT INTO core_settings (k, v) VALUES ('flags', '{"links":{"discord":"https://discord.gg/…","donate":"https://…","kb":"https://…"}}')
   ON DUPLICATE KEY UPDATE v = VALUES(v);
   ```
   Допустимые ключи: `site`, `cabinet`, `news`, `kb`, `forum`, `donate`, `support`, `discord`. Ссылки принимаются только с https.

## Статус сервера
Онлайн и максимум игроков лаунчер берёт прямо с игрового сервера: `http://<ip>:<порт+20>/info` платформы. Пинг — время этого ответа. Если `/info` молчит, лаунчер проверяет вход на `порт+10`; если и он закрыт, показывает «Недоступен».

Поэтому в `core_servers` достаточно адреса с базовым портом (`188.130.132.47:7788`), а `online` в БД — только запасное значение.
