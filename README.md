# 4ONE Launcher

Лаунчер проекта 4ONE RP на Electron: вход через сайт, установка клиента, запуск GTA V, новости, серверы, промокоды.

- **Единый аккаунт.** «Войти через сайт» открывает страницу входа в браузере (логин и пароль — как в игре), лаунчер получает возврат по `gta4one://auth/callback` (OAuth, PKCE). Роль показывается в профиле: «Игрок» или «Администратор n уровня»; для администрации появляется вкладка «Администрирование». Сессия хранится зашифрованно (`safeStorage`).
- **Одна БД.** Профиль, роль, баланс 4Coin, серверы, новости, промокоды, данные аккаунта — из игровой MariaDB через Core API (`backend/core-api`). Лаунчер ничего не хранит «у себя».
- **Коды с сайта.** Вкладка «Коды»: активация промокода, награда сразу на аккаунт, история.
- **Игра.** Поиск GTA V (Rockstar/Steam/Epic), проверка версии (нужна Legacy 1.0.3889.0), установка ScriptHookV и клиента с докачкой и проверкой SHA-256, синхронизация модов, запуск и подключение к выбранному серверу.
- **Обновления.** electron-updater, лента — статика на веб-сервере проекта (`L4_CDN_URL`).

## Запуск
```bash
npm i
npm run start:mock     # демо, код входа KT7M-4XPQ
npm test
```
Боевой режим: разверните Core API (`backend/core-api/README.md`) и задайте `L4_CORE_URL`/`L4_CDN_URL` (см. `.env.example`); контракт — `docs/API.md`.
